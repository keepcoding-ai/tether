Seletor de mesas — desenho escolhido

Cápsula com contorno. Mesa inativa: sem fundo, só o texto na própria cor. Mesa atual: preenchimento forte da cor, com texto de contraste escolhido pela regra (L < 0,55 → texto claro; L ≥ 0,55 → texto escuro). A paleta é a de 12 matizes (--x-{cor}). O selo de atenção usa o laranja --x-alert com um anel na cor da barra, para não se confundir com uma mesa laranja. Clique para trocar de mesa.
