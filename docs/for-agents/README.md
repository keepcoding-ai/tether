# Prévia de interface do tether for agents

Prévia de interface do tether for agents, aprovada pelo PO em 21/11/2026.

## Arquivos

- `for-agents-estrutura.html`: a estrutura em wireframe, com a tabela problema → onde se resolve, que mostra qual problema cada parte da interface resolve e em que lugar ela fica.
- `for-agents-preview.html`: o visual em claro e escuro (botão no canto da página), com a cápsula, as abas, os menus, o diálogo de dar e o inventário.
- `prints/`: capturas das duas versões do visual (`*-light.png` e `*-dark.png`), numeradas na ordem de apresentação.

## Notas da construção

A construção mudou três pontos em relação à prévia:

- A faixa de cor do dono vai de 170 a 330 (a prévia usava 175 a 345), para que a cor de um agente não mude entre versões.
- O texto diz "Dono" sem flexão de gênero.
- A linha "quem comanda" fica na barra de status do painel de terminal.
